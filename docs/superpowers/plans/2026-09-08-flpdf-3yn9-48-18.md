**Goal:** Move the initial `/Prev` walk and trailer diagnostics onto the same qpdf-shaped routes so classic and reconstructed xref reads report identical `readTrailer` behavior.

**Architecture:** Keep `parse_xref_from_start_with_owner` as the one-section parser, but make its callers seed the shared `/Prev` visitor with that section's start offset before walking older sections. Preserve `ByteCursor` and `parse_xref_table` for classic xref syntax; the new helper does not replace classic line parsing.

### Task 2: Implement one qpdf-shaped `read_trailer` helper and route both callers through it

**Interfaces:**

- [x] **Step 1: Add the helper without changing classic table parsing**

  Implement the following behavior:

  ```rust
  fn read_trailer(
      input: &[u8],
      start: usize,
      filename: &[u8],
      resolver: &mut dyn HandleResolver,
  ) -> Result<(ObjectHandle, Vec<QpdfExc>)> {
      let slice = input
          .get(start..)
          .ok_or_else(|| Error::parse(start, "trailer is not a dictionary"))?;
      let parsed = parse_qpdf_file_object_handle_with_diagnostics(
          slice,
          i64::try_from(start).unwrap_or(i64::MAX),
          None,
          resolver,
      )?;
      let mut diagnostics = trailer_diagnostics(start, parsed.diagnostics, filename);
      if let Some(empty_offset) = parsed.empty_offset {
          diagnostics.push(trailer_warning(
              filename,
              "empty object treated as null",
              Some(start.saturating_add(empty_offset) as u64),
          ));
      } else if parsed.value.try_is_dictionary()? {
          let mut tokenizer = Tokenizer::new(slice);
          tokenizer.allow_eof();
          tokenizer.set_position(parsed.next_offset)?;
          let token = tokenizer.read_token(true, 0)?;
          if token.is_word_value(b"stream") {
              diagnostics.push(trailer_warning(
                  filename,
                  "stream keyword found in trailer",
                  Some(start.saturating_add(tokenizer.position()) as u64),
              ));
          }
      }
      Ok((parsed.value, diagnostics))
  }
  ```

  `trailer_warning` must construct `QpdfExc::new(DamagedPdf, filename, b"trailer", ...)`, preserving parser warnings before the post-parse warning. Update `trailer_diagnostics` to use the same object attribution. The lookahead is the only new `allow_bad = true` token consumer; leave `ByteCursor::read_token(false, 0)` in classic xref parsing unchanged.
