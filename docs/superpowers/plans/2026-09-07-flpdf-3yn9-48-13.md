# flpdf-3yn9.48.13 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the production xref-stream and reconstruction object reads onto the resolver that already owns the document's canonical cache, matching qpdf 11.9.0's `readObjectAtOffset` → `readObject` → `readStream` → `resolveObjectsInStream` responsibility chain.

**Architecture:** Extend the existing `CanonicalTrailerOwner` seam with the resolver's live offset-read, raw stream-data, recovered-EOL, and warning-snapshot operations. Make xref parsing consume one context abstraction that can use the canonical owner in production and retain the owner-less bootstrap implementation only for the standalone xref loader tests that have no `Pdf` owner. Pass the canonical owner through initial, hybrid, `/Prev`, and reconstruction-candidate xref reads; do not move reconstruction-only bounded windows into the canonical path.

**Tech Stack:** Rust workspace, `ResolverHandle`/`LiveFileParser`, `ObjectHandle`, qpdf 11.9.0 source mirror, qpdf differential fixtures, cargo fmt/clippy/test, `cargo llvm-cov` patch coverage.

**Spec:** Beads issue `flpdf-3yn9.48.13`; qpdf correspondence row `QPDF::resolve`/`QPDF::resolveObjectsInStream` in `docs/qpdf-correspondence.md`.

## Global Constraints

- qpdf 11.9.0 source and observed `/usr/bin/qpdf` 11.9.0 output are the semantic and byte-output oracle.
- The canonical production owner is `ResolverHandle`; no second production cache, raw `Object` route, `Pdf::resolve` bridge, or qtest-only compatibility shim may be added.
- qpdf's active/canonical object read is unbounded; the existing reconstruction-only 64-offset-position hardening must remain outside the canonical route and must not be copied into it.
- Reuse existing h6fe/q759/scj3/8q38 fixtures and tests; do not add qtest repository fixtures or modify `flpdf-qtest`.
- `.48` is in scope for this resumed route; qtest exceptions remain out of scope.
- Every implementation change gets a RED test before the GREEN implementation, and the final tree must pass the repository's strict rustdoc, all-features clippy, workspace tests, qpdf correspondence/deviation checks, and 100% patch coverage.
