# flpdf ↔ qpdf route matrix — 二重正本トラッカーの symbol manifest
#
# 対象: docs/qpdf-route-matrix/{a..e}-*.md の 162 行のうち、classification が
# `bridge` または `mixed` の 97 行の「flpdf current entrypoint」に現れる flpdf symbol
# （167 個）。`canonical` 行は対象外。bridge/mixed で唯一 entrypoint が `absent` の
# B7 も対象外（qpdf の `QPDF::readToken` に対応する flpdf の集約点が存在せず、
# 追跡すべき symbol が無い）。B29 も `absent` だが `unknown` なので元から対象外。
#
# 使い方:
#   python3 scripts/qpdf-route-callers.py --root .            # 全件を数える
#   python3 scripts/qpdf-route-callers.py --symbol <leaf> --expect-zero
#
# 数え方の規約は scripts/qpdf-route-callers.py の module docstring が正本
# （コメント専用行・宣言行・use 行・impl ヘッダ・文字列リテラルを除外し、
# 呼び出し箇所と型位置を数える。test = tests//benches//examples/ 配下、
# *_tests.rs、および #[cfg(test)] guarded 項目）。tracker は symbol の
# 最後の `::` セグメント（leaf）を whole-word で照合するため、leaf が
# 一致する複数 symbol は 1 つの数字に合流する。
#
# ---------------------------------------------------------------------------
# 2 つのカテゴリを混ぜないこと（README.md §6 参照）
#
#   (a) deletable route — canonical owner が全 consumer に行き渡れば
#       production caller が 0 になる経路。`--expect-zero` が完了判定として
#       意味を持つのはこの群だけ。
#
#   (b) baseline denominator — mixed 行の canonical 側 entrypoint、複数行が
#       共有する primitive、および leaf が総称的で他 symbol と衝突するもの。
#       0 になることは想定されておらず、`--expect-zero` を当ててはいけない。
#       cutover 後に「数が減ったか / 変わらなかったか」を読むための分母。
#
# ---------------------------------------------------------------------------
# 曖昧な leaf（(b) 固定。tracker の数字は行セルを再現しない）
#
#   resolve  (A7)  — `Pdf::resolve` 以外に `PageRange::resolve` 等が同じ leaf。
#                    A7 の行は「`\.resolve\(` 全件 − 非 Pdf receiver 23 件」で数えている。
#   write    (D1, D26) — `PdfWriter::write` 以外に `Pipeline::write` / `write!` 等。
#   Error    (B32) — `crate::Error` の全 variant 参照。行は
#                    `Error::Internal(` / `Error::System(` / `Error::parse(` を個別に数えている。
#   run      (E-1) — `QPDFJob::run` 以外に `driver::run`（E-28）等。
#   check    (E-8) — `QPDFJob::check` 以外に `linearization::check` 等。
#   parse    — 使用不能（prod 292）。E-14 `RotateSpec::parse` と E-15 `PageRange::parse` は
#              leaf ではなく **型名**（`RotateSpec` / `PageRange`）を登録して代用している。
#   main     (E-21) — `fn main` は宣言行なので除外され、prod 0 になる（degenerate）。
#   Plan     (D24) — `writer/pclm.rs::Plan` 以外の `Plan` も拾う。
#
# leaf を共有する行（1 つの数字が複数の行セルに対応する）
#   compute_data_key            C17（reader/writer 共通 primitive）
#   write                       D1 + D26
#   write_qpdf                  E-3 + E-4
#   write_qpdf_to_memory        D30（writer.rs, test-only）+ E-4（flpdf-cli の同名別関数）
#   write_json_with_version     E-6（QPDFJob メソッド）+ E-24（free 関数）
#   finish_file_object_handle   B9 + B10
#   append_xref_and_trailer     D12 + D13
#   prune_acroform_after_subset E-26（free 関数と QPDFJob メソッドが同名）
#   recover_stream_length       B11（mixed、2 実装）+ C42（mixed、pipe-side subtraction は解決済み）
#                               — 領域間の粒度差。README.md §8 の X-1 参照
#   RecoveryPolicy              B11 + B26
#   objstm_membership_linearized_with_eligibility  D6 + D23
#
# 登録しない entrypoint
#   Pdf::drop（A20） — `impl Drop for Pdf` は leaf `drop` が総称的で数えられない。
#                    A20 は `BootstrapCache` / `disconnect_all` / `ObjectHandle::disconnect`
#                    の 3 symbol で追跡する。
#
# 実在しない symbol
#   qpdf_preserve_source_objstm (D29) — PR #1486 の diff にのみ存在し、
#   main（本 worktree）では 0 hit。0 は「cutover 済み」ではなく「未マージ」を意味する。
# ---------------------------------------------------------------------------
